# Reusable library browser direction

Audience: ClearFrame authors choosing an explanatory operation and adapting an existing specimen. The primary job is to find a useful source, see its actual preview and understand what has been checked. The inventory remains the planning authority; the browser does not install assets or promote their readiness.

Palette: cool studio background #F1F4F9, white preview surface #FFFFFF, graphite text #263348, blue selection #1847CF, green verified-file text #216747 and amber review text #8B5B06. These colors organize availability and selection; the actual specimen retains its authored colors.

Type: bundled Space Grotesk for the library title and specimen headings; bundled Inter for controls, descriptions and evidence. Use existing OFL fonts, without downloads. Sentence case throughout. Asset IDs have meaning as inventory references, not decorative numbering.

Layout alternatives considered:

- A uniform card wall exposes many previews but hides evidence and repeats nearly identical format variants.
- A research table preserves metadata but makes the motion secondary.
- A three-part workbench keeps a searchable results rail, one large preview and an adaptation/evidence inspector visible together. This is the chosen structure.

Desktop:
```
Search and collection / purpose / medium / readiness filters
[ result thumbnails ] [ one controlled preview ] [ source and review ]
[ result titles     ] [ format controls         ] [ adaptation notes ]
                     [ recent declared choices and variation context ]
```
Mobile stacks results, preview and evidence; the results list is bounded so the player remains reachable. All controls are keyboard accessible, focus is visible, media never autoplays, and only one video can play. The bold element is the preview itself; no decorative animation or background effects.

Generic-plan critique: an initial card-grid idea would hide the difference between source-only concepts, prepared Blender inserts and rendered native specimens. The selected workbench uses explicit availability and readiness labels, shows a prepared insert as such, and keeps source/evidence beside the picture. Palette or seed changes alone do not count as new concepts in the variation ledger.

T08 records declared mechanism/material/camera/story choices alongside an exact storyboard hash. Example history is labelled as example history. It does not infer semantic novelty from primitive counts, fabricate production use, force alternatives, or claim that a different color makes a different concept.

Verification: fixture checks for safe paths, stale/missing files, status and source-to-variant mappings; actual browser interaction at desktop and phone widths; keyboard navigation, filters, format selection, video play/seek, source links, no-result states and variation export/import. Independent review must inspect the browser and its evidence before publication. Original motion assets keep their existing lifecycle and review limitations.
