Import a ledger

Paste a ClearFrame ledger to inspect it here. Imported source hashes are declarations until checked against the actual project. Import replaces this browser session; export to keep changes.

Record a project's choices

Use the CLI to bind your declared choices to the current storyboard. Set mechanisms, materials, camera and story in a choices JSON file.

node engine/cli.mjs library-log my-film --choices choices.json --ledger my-series.json --assets R03

The ledger never changes a film. A repeated operation can be the most truthful choice.
