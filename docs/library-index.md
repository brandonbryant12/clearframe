# Library index

Generated by `node engine/cli.mjs find --index`: everything a film can be built from, one line each. Search it with `find "what you want to show"`; `find --id kind:name` prints the exact authoring. The studio agent uses the same index (`clearframe_catalog` topics `find` and `item`).

## block

- `title` — Open with a clear promise: display type rises line by line under an accent bar.
- `statement` — A single editorial statement with optional accent phrases and a supporting line.
- `stat` — A hero number with units, counted from a truthful starting value.
- `kpis` — Two to four comparable metrics with staggered entrances.
- `bars` — Accurate zero-based comparison with a tunable focus.
- `line` — A progressive time-series reveal on an explicit scale.
- `waffle` — Countable units for a share or probability; tiles fill one by one, optionally as icons.
- `ring` — A single proportion with an exact counter and units.
- `delta` — Before and after: the new value counts from the old one; the change chip can carry meaning.
- `compare` — Two approaches with matched criteria and a verdict.

- `quote` — A sourced human voice in light display type with an oversized mark.
- `matrix` — A compact comparison grid for two to four criteria; one column can be highlighted.
- `equation` — Build a simple relationship, then show its implication.
- `callout` — A framed correction, caveat or key insight with an optional icon badge.
- `endcard` — A deliberate ending; the next step becomes a call-to-action pill.
- `image` — A real or generated plate at its own aspect ratio, in a rounded mask.
- `video` — A short footage insert with native titles and a shared soundtrack.
- `kinetic` — Speech-following words: highlight a phrase, reveal words, one at a time, or stack them as poster type that builds as spoken.
- `flow` — Draw connections as a process unfolds; each node can follow a spoken cue.

- `breathing` — An expanding and contracting ring with explicit, editable phase durations.
- `chapter` — A section opener: an oversized number, a rule that sweeps and the chapter title.
- `highlight` — A sentence whose key phrases get a marker sweep, each on its own cue.
- `donut` — Part-to-whole: segments sweep in order; the legend states each value and share.
- `magnitude` — Area-true squares for quantities that differ by orders of magnitude.
- `checklist` — Items appear unchecked, then each box fills and ticks on its cue.

- `annotate` — A screenshot or photo with numbered pins, a matching legend and an optional focus region.
