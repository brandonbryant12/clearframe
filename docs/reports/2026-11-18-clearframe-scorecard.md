# ClearFrame engineering and authoring scorecard

**November 18, 2026 · 76.1/100 after the upgrade, up from 64.6/100.** ClearFrame can turn an inspectable storyboard into a deterministic native film. An agent can find a real shot, copy its editable structure, attach measured speech and inspect what the renderer saw. The biggest remaining uncertainty is how often an unfamiliar agent chooses a picture that actually explains the source material on its first attempt.

## Scope and scoring

The baseline is the standalone repository at `74a3d80`. The second column of scores covers the changes in this branch. Each score is an engineering judgment on a ten-point scale. A 5 means the capability exists with material manual gaps, 7 means an ordinary workflow is repeatable and tested, and 9 requires independent evidence across representative inputs. A 10 additionally requires a measured, maintained completion criterion. The overall is the sum of weight × score divided by 10. Test pass rates, subjective scores and model benchmarks measure different things. The weights favor upstream reuse, timing and repeatable agent output, as requested.

| Area | Weight | Before → after | Evidence and limiting factor | Improvement that would raise the score |
|---|---:|---:|---|---|
| FFrames reuse and custom runtime | 12% | 6.5 → 8.5 | FFrames schedules GOP-aligned segments, writes H.264 and joins them. The production compositor now uses its cue and word state. Removing the RGBA pipe leaves one production encoder. The custom backend still converts Skia frames and handles CPU/GPU readback. | Prototype the upstream backend on the same plans. Compare decoded frames, chroma edges, range boundaries and peak memory before retiring another local stage. |
| Footage, geometry and seeking | 8% | 8 → 8 | The native adapter handles non-square pixels, display rotation, delayed B-frames, mixed frame rates and backward seeks. Upstream 1.4.1 handles sample aspect ratio. Its Clip duration rounds down a partial output frame. | Run both decoders on the same rotated anamorphic and 24→30 fps fixtures. Require the last sample, reverse-seek identity, dimensions and roundness to match. |
| Captions, timing and accessibility | 10% | 6.5 → 8.5 | Broadcast cues and animated word state now use FFrames. JSON retains measured intervals and gaps. Rough speech exports phrase text and its timing provenance. WebVTT/SRT remain available. Placement follows the prepared beat, including during repeated server requests. | Add a multilingual fixture with adjacent-script tokens, punctuation, two speakers and a phone-safe caption review. Measure overlap and reading rate at delivery size. |
| Agent discovery and editable building blocks | 10% | 6.5 → 8 | Five system diagrams are editable JSON, including parallel checks and exception routing. The same diagram can be found, edited and rendered through a project library. Neon chooses a supplied library ID and the catalog supplies the authoring example. | Give each common explanatory mechanism an example, a poor-fit example, a visible acceptance check and a rendered phone thumbnail. |

| Audio, mix and finishing | 6% | 7.5 → 7.5 | The existing finisher handles narration, music, ducking, normalization and final mux checks. Measured words link sound to picture. | Gemini lifecycle and API coverage | 8% | 4.5 → 8 | The release adds Neon direction, Nano Banana 2.1 stills and Omni 1.2 video. | Cost, cache identity and retry behavior | 6% | 6.5 → 7.5 | Plan and execution share effective image model and output size. Still and clip identities include reference content. Neon estimates a token ceiling, and paid video avoids automatic retries after uncertain results. Per-call estimates leave variable provider charges and concurrent spend open. | Add durable admission and per-run receipts that reconcile measured usage with estimates and handle interrupted requests. |
| Code organization and ownership | 6% | 6.5 → 7 | The CLI, engine, authored library and native renderer have useful boundaries. Three executable diagram wrappers became data. There are 237 source files directly under `engine/lib`, alongside subdomains, and shared Google transport resides under the TTS skill. | Extract the Google transport behind its current imports, then group the next frequently changed feature with its schema, planner and adapter. Track import cycles and public API stability. |
| Automated verification and distribution | 8% | 7 → 8 | Workspace checks cover schemas, types, behavior and packaging. Native CI now builds the locked Rust dependency, runs fixtures and reads a real WebVTT file through the binary. A passing unit suite alone cannot qualify an encoded film or a vendor account. | Promote a small decoded landscape/portrait comparison into a release check and keep its expected hashes and encoder receipt with the release. |
| Installation and platform reach | 4% | 4 → 4.5 | The CLI and pure-data paths run under Node. The production painter depends on Apple Metal, Rust/Skia and media tooling. CI produces a tested macOS artifact. The public install still has a source-build path and platform limits. | Publish signed macOS binaries with source hashes and verify on a clean machine. | Performance, operations and observability | 2% | 6.5 → 6.5 | Worker limits, persistent caches, timing and encoder receipts exist. | Trust, provenance and licensing | 2% | 7.5 → 7.5 | FFrames has a pinned revision and license digest. ClearFrame records source and media evidence, accepts project libraries as JSON, and constrains model-selected IDs. Its linked FFmpeg/x264 distribution has separate licensing obligations. | Produce a release dependency/license inventory and verify provenance survives exporting and re-importing one project on a second machine. |

## Where upstream should take over next

| Priority | Work and expected leverage | Acceptance criterion |
|---|---|---|
| 1 · small | Exercise FFrames Clip through the playable interval and display transform. This isolates the two behaviors that still justify maintaining a decoder. | A 49-frame, 24 fps clip supplies all 62 valid output samples at 30 fps. The next sample is absent. A rotated anamorphic disc has the same display size and shape after backward seeks. |
| 2 · medium | Run a controlled agent evaluation before adding more broad-purpose presets. Use 12 briefs spanning a mechanism, a process, a quantitative claim and an exception. Have two independent agents author each brief with the same source and budget. | Publish results for all 24 attempts. Review factual fidelity, choice of mechanism, phone legibility, timing and viewer comprehension separately. Record first-pass acceptance, revisions, time and cost, including failed attempts. |
| 3 · medium | Test upstream audio analysis and mixing behind the current finisher. Narration onset and music ducking are the behaviors most likely to affect an audience. | Compare emitted PCM and muxed output on recorded speech, music ducking and silence. Require identical frame counts and speech onset within one frame. Set and publish LUFS and true-peak tolerances before comparing the mixes. |
| 4 · small | Move the shared Gemini transport and contract fixtures out of the TTS-specific directory. Keep the specialized modality adapters and their existing import paths during migration. | Text, transcription, TTS, image, music and video tests use the same transport fixture. A retired model or invalid duration produces zero network requests. |
| 5 · medium | Package the renderer and make picture verification a release artifact. This removes initial compilation as a barrier for new agents and exposes upstream regressions before a film project discovers them. | On a clean Mac, install, render both orientations, inspect one measured word on the command line and verify the decoded comparison and renderer provenance. |

FFrames also offers optional GPU layers and 3D rendering. An extra graphics stack would add compilation cost and a second drawing contract. Pick one brief that needs an effect ClearFrame currently cannot express, then compare the resulting film and implementation size before enabling those features. ## Evidence and reproduction

The published FFrames tag is `v1.4.1` at `49b76066abbc`. The previous ClearFrame pin was the October 18 snapshot `28356c5b5473` after the 1.2.0 tag. Native code uses the upstream validated caption data and end-exclusive state. The footage interval comparison is in `packages/engine/src/scene/native/src/media.rs`. [Caption implementation](https://github.com/dmtrKovalenko/fframes/blob/v1.4.1/fframes-media/src/subtitles_data.rs) · [Clip implementation](https://github.com/dmtrKovalenko/fframes/blob/v1.4.1/fframes/src/clip.rs)

Google announced Gemini 4 Neon on November 18. The separate modality-specific models are Nano Banana 2.1 for images, Omni 1.2 Flash for video, Gemini 3.8 Flash TTS for narration, Gemini 3.5 Transcribe for timing and Lyria 3.5 for music. Checks in this review used local data and simulated Google responses. [Release notes](https://aistudio.google.com/docs/changelog) · [Models and prices](https://aistudio.google.com/docs/pricing) · [Retirement dates](https://aistudio.google.com/docs/deprecations)

Reproduce the authoring checks with a built workspace:

```sh
pnpm cf find "two independent reviews" --kind sketch --json
pnpm cf find --id sketch:exception-route
pnpm cf find "parallel reviews" --neon --dry-run
pnpm cf captions FILM
pnpm cf caption-track FILM/build/captions.fframes.json --at 2.5
```

For machine checks, run `pnpm guardrails`, `pnpm test:package` and `cargo test --release --locked --jobs 1 -- --test-threads=2` in the native crate. The full picture comparison accepts a previously tested binary as its reference via `node scripts/verify-runtime.mjs OUT PREVIOUS_BINARY`. Existing October performance and image comparisons remain historical measurements.
