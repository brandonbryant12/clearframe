# Scene engine coverage

Generated by `node scripts/engine-coverage.mjs` from the code, `scripts/engine-parity.mjs` and `scripts/engine-bench.mjs`. States:

- **native** — drawn by the scene engine itself (Skia/GPU), no SVG involved;
- **block layer** — drawn by the unchanged `fframes/native` block code as an SVG input layer inside the scene engine's GPU canvas (identical code in both engines; the compatibility path, to be ported);
- **replaced** — the scene engine reimplements what FFFrames drew, with the same rules, and parity is measured;
- **refused on stages** — available in canvas/art (block layer) but rejected by name on a native stage;
- **unverified** — not exercised by a test, harness or rendered fixture in this change.
