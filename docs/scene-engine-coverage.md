# Scene engine coverage

Generated by `node scripts/engine-coverage.mjs` from the code and the reference comparisons. Everything listed is drawn by the renderer itself (Skia on Metal): blocks as display lists, stages as native elements, film-level layers natively. FFFrames is retired; the PSNR columns compare each still with the same moment in the retained FFFrames-era run (`build/parity`, `build/parity-gallery`, `build/engine-effects`), which is how a change in the picture was measured without a second renderer. About 50 dB and above is indistinguishable in review; lower values were inspected and come from noise-driven textures, halftone fields and rough strokes.

- **native**: drawn by the renderer;
- **refused on stages**: available in a `canvas` beat or `art`, but rejected by name on a native stage;
- **unverified**: not exercised by a test, harness or rendered fixture.
