# Native dimensional KPIs

Five editable native templates: a decorative pedestal, a zero-based comparison, a progress rail, a contribution stack and a qualitative seesaw. All values are illustrative. Change the literal `props.kpi` inputs and render; no Blender or media generation is needed. Data front faces use exact values and shared scales. The seesaw angle is a comparison metaphor, not measured torque.

See [direction, data contracts and motion guidance](../../docs/kpi-direction.md). This example also works through `clearframe new <dir> --playbook dimensional-kpis --vertical`.
