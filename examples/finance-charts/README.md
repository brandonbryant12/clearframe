# Finance chart templates

Six editorial chart beats for market and personal-finance commentary, in the `ledger` palette. Each is a `canvas` beat using `props.plot` ([docs](../../docs/quantitative-plots.md)), so it stays native, editable and sourced.

| Beat | Pattern | Use it for |
|---|---|---|
| `compounding` | Log-scale index, recession bands, area fill, trough callout | Long-run market history, any compounding series |
| `purchasing-power` | One declining series with area | Inflation, fee drag, currency erosion |
| `real-nominal` | Two indexed series from a common base | Wages, returns or spending before and after inflation |
| `yield-curve` | Two snapshots on a linear x axis | Yield curves, term structures, any cross-section at two dates |
| `drawdowns` | Decline from prior peak with recession bands | Risk, recovery time, the cost of volatility |
| `scenarios` | History, then three projections inside a shaded band | Planning ranges, return assumptions, outcomes by rate |

## Use

```sh
node examples/finance-charts/build.mjs        # regenerates storyboard-landscape.json and storyboard-vertical.json
mkdir -p build/charts && cp examples/finance-charts/storyboard-landscape.json build/charts/storyboard.json
node engine/cli.mjs check build/charts --draft
node engine/cli.mjs still build/charts --at 8.6 --draft
```

Copy a beat into your film, replace the series, title and `source` with real, attributable data, and keep the storyboard `sources` entry. Every value here is illustrative: the index, wage and scenario series are generated by `build.mjs`, and the yields are rounded examples, not quotes.

Check a still of every beat in each format you ship. The plot rejects tick labels that would overlap, and `check` flags type that is too small for a phone or outside the title-safe area; fix those rather than shrinking type.

Renders go to `build/` and are never committed.

Give each the same pass (frame-filling layout, quiet axes, collision checks, a template beat here) before using it in a finished film.
