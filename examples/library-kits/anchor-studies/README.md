# Anchor studies

Eight native specimens attach editable labels to static points on two original prepared Blender mechanisms. Four cases—access gate, settled level, alternate route and fixed bottleneck—each have landscape and vertical compositions. Open [preview.html](preview.html) for the clips or [REVIEW.md](REVIEW.md) for independent evidence.

The source movement lasts eight seconds. The final pose then holds for twenty seconds as native copy, a leader and a ring appear. The explanatory geometry is qualitative; the visible qualifications exclude balances, measured throughput and other quantitative interpretations.

## Reuse

- Edit `inputs.json` for editorial copy and `definitions/` for local points or copy zones.
- Export each changed definition with `asset-anchors`; see [the command contract](../../../docs/asset-anchors.md). A changed source requires a new export.
- Run `node examples/library-kits/anchor-studies/build.mjs` to build native storyboards. The original prepared scenes and receipts are dependencies in `../physical-mechanisms/media/`; the playable specimen media is copied inside each specimen.
- Run `verify.mjs` through the shared resource gate, then source, projection and encoded checks and independent review before repackaging with `package.mjs`.

`anchors/` retains exact source-bound manifests. `audit.json` records native placements and source identities. `evidence/` retains encoded clips, receipts, native jobs, phone sheets, boundary checks, seek hashes and independent review. `kit.json` hashes the distributable files. No network or paid provider is required for playback.

## Scope and limits

**Prototype.** The anchor range is static, zero-based and half-open. Every declared source frame is checked for geometric stability. The actual matrix-projection check is independent of the exporter's projection function. All 48 frames of each repeated hold clip match the original final decoded YUV frame.

Copy regions clear conservative projected mesh boxes with padding. They do not prove rendered visibility, occlusion, shadow clearance, face/edge connectivity, material stability, contrast or glyph fit. Native checks and sampled encoded phone review cover the current compositions. Bounded probes do not establish subjective continuous playback or final master acceptance. Moving anchors, occlusion intervals, arbitrary cameras and square/4:5 remain unreviewed.
