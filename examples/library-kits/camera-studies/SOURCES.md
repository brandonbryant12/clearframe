# Sources and assumptions

All meshes, paths, materials and explanatory scenarios are original procedural ClearFrame work. No external models, footage, measured datasets or paid generation are used. The manifold is a visual connection metaphor, the fifteen markers are illustrative objects, and the two panels demonstrate selective focus. None represents an engineered product, observed network, population count or optical measurement.

The technical implementation uses Blender's camera location, lens, shift and depth-of-field settings. API references: [Camera](https://docs.blender.org/api/3.6/bpy.types.Camera.html) and [CameraDOFSettings](https://docs.blender.org/api/3.0/bpy.types.CameraDOFSettings.html). Retained receipts record the installed Blender version actually used. Reference versions explain properties; they do not substitute for the local render evidence.

`focus-depth` uses deliberately exaggerated defocus to remain legible at phone size. Native captions remain sharp; blur never establishes the truth or strength of an evidence claim. Close openings intentionally crop context. Final framing is separately fitted for each demonstrated aspect ratio.

Original files and procedural artwork use the repository MIT license. The native compositor's bundled fonts retain their own OFL notices. No rights in unrelated third-party assets are granted.
