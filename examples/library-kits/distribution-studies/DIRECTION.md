# Distribution studies

Original fictional observations, native editable charts, two formats. C13 asks how supplied observations occupy explicit bins and how many cross an authored threshold. It does not fit a bell curve or predict a future tail probability.

## Decisions

Library validation mode: implement and review without a film approval checkpoint. Paper treatment, geometric type, blue bars, ink outlines. Count mode uses equal widths; density permits unequal widths. Landscape and vertical keep identical observations, bins, scales and threshold membership. All marks retain exact x positions. Dot rows only prevent collisions.

The first 32-second beat reveals bars from their zero baseline in bin order with linear motion, keeping all observations visible underneath. Counts appear when each bar settles. The second beat preserves the complete histogram and dot strip, draws an exact threshold and outlines every qualifying observation. A direct count states the answer. No partial-bin shading or tail-area interpolation.

Hold most of each beat for reading and inspection. Static holds and fixed camera are intentional for this chart specimen. No camera effects, decorative particles, audio, generated media, real-world claims, paid calls or forecast. This is a reusable prototype, not a finished narrated film. Continuous playback and final master acceptance remain open.

Review bar width/height, baseline, zero bins, endpoint membership, count labels, density units, missing denominator, threshold equality, highlighted markers, contrast and phone readability. Inspect reveals and the cut as well as settled frames. Test math independently and bind every result to the current source and encoded artifact.
