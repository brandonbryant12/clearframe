# Provenance and conceptual boundaries

All scenarios, values, dates, compositions and source code in this kit are original fictional examples. No observed market trajectories, publisher screenshots, branding or copied chart pixels are included. C02/C03/C16 connect to the research inventory as reusable explanatory ideas; these assets do not claim a Timmer-derived visual style.

Primary references consulted October 2, 2026:

- [S&P Dow Jones Indices — Index Mathematics Methodology](https://www.spglobal.com/spdji/en/methodology/article/index-mathematics-methodology/). Conceptual boundary: total-return index methodology includes reinvestment treatment. Our earnings-times-multiple plus separate cash identity does not implement such an index.
- [IMF — Purpose of the Government Finance Statistics Manual 2014](https://blog-pfm.imf.org/en/pfmblog/2014/08/purpose-of-the-government-finance-statistics-manual-2014-gfsm-2014-the-gfsm-2014). Conceptual context for relating opening and closing stocks to transactions and other economic flows. Our supplied changes and unexplained residual are fictional algebraic reconciliations, not official statistics or an implementation of that manual.

The formulas, bounds and display obligations are explicit in [data-transforms.md](../../../docs/data-transforms.md). These sources are conceptual references only. The input SHA-256 and retained render receipts provide the actual evidence chain for each specimen.
