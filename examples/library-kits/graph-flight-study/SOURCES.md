# Provenance

Original ClearFrame Python geometry, materials and camera motion under the repository MIT license. The source brief came from the user: weave along the time axis of a flat 2D bar chart, pull out to the full chart, and slow the camera. No outside artwork or reference image was imported.

Both datasets in inputs.json are fictional, authored 2026-10-03. Multiplying the reserve fixture by 100 yields illustrative USD amounts; these are not real account records, returns or forecasts. The second fixture gives fictional workload hours. Native labels have not yet been rendered or accepted.

Each retained pass includes exact source hashes, a baked Blender scene and render receipt. Historical and rejected passes remain separately named and do not describe the current sampler. The independent review scripts reject changed source hashes. Review reports preserve original paths; retained-views.json maps stills into this portable evidence directory.
