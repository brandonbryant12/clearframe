# Dated phase trails

**Prototype.** C15 has editable native source for two fictional paired-observation studies, each composed in landscape and portrait. All four final native clips have zero layout errors/warnings, zero detected pops and matching shuffled seeks. Independent review covers the model and 64 actual decoded phone frames. Continuous playback and master acceptance are not claimed.

- **Orders and inventory:** monthly order changes turn negative while inventory remains above that month's plan. Missing inventory in August breaks the trail. The focus is June's upper-left quadrant.
- **Load and temperature:** irregular dates retain their actual elapsed spacing. Nonzero comparison references separate warmer/cooler and higher/lower load. The selected date lies exactly on both references; missing load and temperature remain separate incomplete rows. The reference is not a safety limit.

Each 72-second native specimen has a 36-second trail build and a 36-second dated inspection. Twelve seconds of reveals follow calendar time, then hold for reading. Observed markers stay at supplied coordinates. Straight connecting segments are guides only; gaps, dates and references stay explicit. These fictional patterns establish no causal mechanism, repeating sequence or forecast.

The pure model is [phase-data.mjs](../../../fframes/phase-data.mjs), with native composition in [phases.mjs](../../../fframes/phases.mjs) and the complete [contract](../../../docs/phases.md). Edit `inputs.json`, then run `node examples/library-kits/phase-studies/build.mjs` from the repository root. The input hash and all generated coordinates are retained in `audit.json`. Source rebuilds are lightweight; full rendering uses `codex-heavy`, two supported workers and at least 20 GiB free.

`DIRECTION.md` records the visual choices; `SOURCES.md` distinguishes original fixtures from the method reference. New copy/data, more crowded trails, new format ratios, smoothing and inferred cycle models require fresh validation and review. No paid generation, borrowed dataset or external art is included.

The RGB probes sample the marker core to avoid downsampled rim chroma; exact source radii and phone inspection provide separate shape evidence. Storyboards and the audit reproduce byte-for-byte. Intentional reading holds have no critique warnings.
