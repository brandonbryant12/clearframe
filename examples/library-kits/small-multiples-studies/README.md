# Small-multiples studies

Four native 78-second clips compare ranked histories with shared axes, then expand one selected panel. Delivery duration and household net flow provide distinct original fictional cases, each composed for landscape and vertical. See [preview](preview.html), [independent review](REVIEW.md) and [the reusable helper](../../../docs/small-multiples.md).

## Read the comparison

The first grid shows the full January–June record ordered by the January value. The next grid retains the identical records and axes but uses June for ordering. This is a cut between declared ranking snapshots, not a forecast vintage or an animation of intermediate rank values. Ties share a competition rank and keep stable ID order. A missing final observation remains unranked instead of silently using May.

The selected panel then enlarges uniformly. Its x/y domains, null gaps and values do not change. The delivery case selects a tied leader; the household case selects a negative flow. Selection means attention, not endorsement or a claim that the series is best. Household flows are not balances or returns.

## Reuse and evidence

Edit `inputs.json`, then run `node examples/library-kits/small-multiples-studies/build.mjs`. `fframes/multiple-data.mjs` handles ranks and `fframes/small-multiples.mjs` emits native canvas groups. Text, colors, source labels, dates and values remain editable. The source includes every explicit date/null; `audit.json` retains the exact sorted models, domains, placements and storyboard hashes.

Render through `verify.mjs` under the shared resource gate. It preserves native layout/QA/boundary reports and deterministic shuffled-seek hashes, then removes its own duplicated raw build files. `check-encoded.py` independently recomputes ranks, verifies native geometry and streams bounded decoded-pixel probes for observation positions, reveal fronts, missing columns, disappearing panels and intermediate expansion. Review and rerun checks after edits before using `package.mjs` to refresh file hashes.

**Prototype.** The retained evidence supports current sampled frames and mathematical mapping; it does not establish continuous subjective playback or final master acceptance. More than four panels, independent scales, square/4:5 layouts and arbitrary new copy remain unreviewed. The current four clips use silent native animation, original data and bundled fonts; no paid generation, external observations or synthetic voice was used. Original source and copy are MIT; bundled fonts keep their OFL notices.
