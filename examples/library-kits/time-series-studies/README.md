# Time-series studies

Twelve native specimens explain three transformations of original fictional dated records: nominal to real (C09), level / growth / change in growth (C10), and observed drawdown with complete-window sample volatility (C11). Each of six cases has landscape and vertical compositions. Each 40-second specimen has a twenty-second method view and a twenty-second quantitative view, with the reveal complete by 4.95 seconds inside the latter.

**Prototype.** Read `REVIEW.md` and `evidence/summary.json` for actual evidence. Silent draft motion examples are not a narrated final film; subjective continuous playback and final master acceptance remain unverified. No forecasts or historical financial results are depicted.

Open `preview.html`, then edit `inputs.json` and run from the repository root:

```sh
node examples/library-kits/time-series-studies/build.mjs
/Users/brandon/.local/bin/codex-heavy -- env CLEARFRAME_HEAVY_HELD=1 node examples/library-kits/time-series-studies/verify.mjs
/Users/brandon/.local/bin/codex-heavy -- python3 examples/library-kits/time-series-studies/check-encoded.py
node examples/library-kits/time-series-studies/package.mjs
```

Use the equivalent resource gate on other machines; rendering needs the native compositor environment. `verify.mjs` handles one specimen at a time, retains hash-checked compact evidence, and prunes only its own generated build directory. Retain at least 20 GiB free before expensive rendering. Regeneration must be followed by source/math and encoded visual review before packaging; changing data can require new domains, ticks or label layout.

`engine/lib/time-series.mjs` is the reusable calculation API. `source/panels.mjs` composes exactly three linked native panels, accepts explicit dated axes, uses independent linear y axes and preserves null gaps. C09 uses the shared `canvas.props.plot` expansion. Text, labels, axes and quantitative geometry remain editable native elements; the MP4 is only the preview.

`audit.json` binds the input hash to unrounded computed values. `check-encoded.py` recomputes the fixture arithmetic independently in Python, verifies source-to-native point/area coordinates and checks encoded dots, null columns and linear reveal fronts. Its scope is bounded sampling, not complete pixel equality. Native shuffled seeks separately verify deterministic sampled frames. `kit.json` records every retained file hash.

Read `SOURCES.md` for calendar anchoring, deflation basis, endpoint growth, percentage points, sample SD and observed-only drawdown limitations. Square and 4:5 have not been composed or reviewed. General monthly/quarterly/annual calculations are supported; this visual kit illustrates annual deflation and monthly unannualized changes only.
