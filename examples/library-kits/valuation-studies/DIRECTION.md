# Valuation sensitivity studies

C14 asks which assumptions change a model value and what one controlled cross-section says when other inputs remain fixed. Use a flat numeric heatmap followed by the exact same sampled cases on a native line chart. Never use perspective to imply quantitative depth.

## Decisions

Library validation mode: implement and review within the ongoing build-out. Two original fictional subjects: perpetual payments with invalid growth/discount cells; a five-year project with upfront cost, negative values and a valid zero at equal growth/discount. Neither is a market forecast, probability, recommendation or full business valuation.

Paper treatment, geometric type and native labels. Pale orange/blue encode signed modeled value, not desirability; exact numbers and a declared legend carry meaning. Gray with an em dash means outside the perpetual model domain, distinct from numeric zero. Both formats preserve the same inputs, rates, scale and selected cell. Midpoint cell boundaries retain the numeric spacing of sampled assumptions; cells represent grid evaluations, not an interpolated surface.

First beat: reveal the complete heatmap in diagonal order. Outline the selected row or column, with a stronger selected cell. Second beat: retain source, outlay, horizon/terminal rule and fixed assumption; linearly reveal the same evaluated slice points. Segments are explicit visual guides, not values evaluated at every intermediate rate. No bridge across invalid points. Portrait has deliberately larger vertical separation; landscape uses width for the same grid.

Each beat lasts 36 seconds. The long final holds are intentional reading and inspection time. No audio, captions, generated art, paid calls or decorative motion. This is a reusable prototype, not a finished narrated film. Review both formats at phone size, intermediate reveals and joins, undefined/zero distinction, labels, shared scales and source clearance. Continuous subjective playback and final master acceptance remain open.
