# How a review moves

Two silent canvas beats demonstrate how an agent can illustrate a rule with an editable diagram. In the first beat, tests and review begin together and release waits for both. In the second, a qualifying request is approved and an exception reaches a reviewer.

Run `clearframe draft examples/review-routing` to render a landscape cut. To adapt it, copy the project, set `format.preset` to `vertical` and render the copy. Check the fork, the join and the exception at playback speed and at phone size. The shapes should retain their identities across each handoff.

`clearframe find --id sketch:parallel-checks` and `clearframe find --id sketch:exception-route` return the editable source. Replace a beat’s `props.sketch` with the returned `props.diagram` to change labels or timing. Use a project JSON sketch to share the change across films.
