# Think, reveal, explain

Four native beats demonstrate a multiple-choice question and a sentence completion. The arithmetic is explicit: 4% to 5% is a rise of 1 percentage point, or 25% relative to 4%. The sequence is a video, not a clickable quiz.

Run `clearframe pipeline examples/teaching-sequences --draft --scale 0.5 --json` to review it. Change paired question/answer content together, keep an exact visible source, and review the reading and answer holds. Native type stays editable.

See [teaching direction](../../docs/teaching-sequences.md) for the helper contract and how to pair a still question poster with a one-way 3D answer clip. The full native example uses no external assets.
