# Dimensional data — editable native templates

Audience: Directors choosing a restrained dimensional treatment for a small set of metrics

Inputs: Replace illustrative values, labels, units, scale and visible source before publication

Native dimensional geometry, not a Blender render. Edit the literal values and render. Front heights and lengths encode exact data on shared scales; the fixed pedestal and fixed seesaw weights are decoration. Seesaw tilt expresses which value is larger, not measured torque or a physical model. The stack preserves any remainder against an explicit total. Keep units and sources visible. Use motion:none for a static presentation. Prefer flat charts for dense, signed or very close comparisons.
