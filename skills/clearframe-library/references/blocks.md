# Native block reference

Generated by `clearframe blocks --md`. All blocks render in FFFrames.

## title

Open with a clear promise: display type rises line by line under an accent bar.

| Prop | Meaning |
|---|---|
| title | Scene headline |
| kicker | Short eyebrow |
| source | Visible attribution |
| land | Spoken word or local seconds |
| support | Supporting line |
| text | Main promise |
| emphasis | Up to 4 whole-word phrases drawn in the accent color |
| emphasisStyle | accent or serif (italic Instrument Serif, the editorial accent). Unset, the film type voice decides: accent, italic, weight, marker or underline |
| align | left (default) or center: centre the whole stack |

```json
{
  "id": "title",
  "block": "title",
  "vo": "Replace this narration.",
  "props": {
    "kicker": "Field notes",
    "text": "Make the next step clear",
    "support": "One idea, supported by evidence.",
    "source": "Illustrative sample data · replace before publishing"
  }
}
```
