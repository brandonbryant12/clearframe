# Existing Veo footage

The Gemini Developer API retired the three Veo 3.1 preview endpoints on October 22, 2026. An existing MP4 can be used as a file asset. To generate another take, change the asset model to `gemini-omni-1.2-flash`, review the continuity references and run `clearframe plan DIR` for the current price.
